更新日期：2026年10月21日。此应用供账号所有者个人使用，按其明确授权发送研究报告或研究未完成通知，不提供交易执行服务。

授权与数据

Google授权仅申请Gmail发送权限（gmail.send），用于通过所有者的Gmail发送邮件。应用不申请读取收件箱、通讯录或管理邮件的权限。收件人为所有者预先指定的地址。

发送内容包括研究报告、研究完成状态、来源与缺失项说明。邮件正文及地址会提交给Google Gmail，并由收件人邮箱服务处理。刷新凭证保存在所有者GitHub仓库的加密Secrets中，不进入公开网页、源码或日志。

存储和用途

报告和安全审计保存在所有者的私有GitHub仓库中。审计记录发送时间、报告哈希、服务响应与消息ID，服务于防重复投递和故障核验。Actions运行产物通常保留30天，Git存档和防重预留持续保留，直到所有者另行管理。不会把令牌、授权码或原始服务错误写入报告或公开记录。

此公开说明页面不嵌入分析或追踪程序。应用不出售用户数据，不将Google用户数据用于广告或通用模型训练。使用与传输Google API获得的信息遵守Google API Services User Data Policy，包括适用的Limited Use要求。

停止与撤销

账号所有者可以停用GitHub Actions邮件工作流，或在Google账号的第三方连接中撤销此应用授权。撤销后无法继续通过该授权发送邮件；已发出的邮件由各邮箱服务及收件人控制。所有者可通过自己管理的Google Cloud项目和GitHub仓库检查、停止或删除应用数据。

本说明不表示Google已验证此应用，也不承诺令牌永久有效。研究未满足条件时应明确标记未完成，不构成收益保证。
